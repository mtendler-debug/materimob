Política de Privacidade

Última atualização: 6 de setembro de 2026

O MaterImob (materimob.com.br) é uma plataforma para corretores e imobiliárias, operada por Mater Estate. Esta página explica quais dados coletamos, para que usamos e como você pode entrar em contato sobre eles.

Quais dados coletamos

Dependendo de como você usa o MaterImob, podemos coletar:

  • Dados de conta do corretor: nome, e-mail, telefone, CRECI.
  • Dados de clientes cadastrados por um corretor no CRM ou no Avaliador de Imóveis: nome, telefone, preferências de imóvel e avaliações registradas.
  • Mensagens trocadas pelo WhatsApp com o número comercial do MaterImob, quando essa integração está ativa, para dar continuidade ao atendimento e manter o histórico da conversa.

Como usamos esses dados

Usamos os dados para operar a plataforma: autenticar corretores, exibir o portfólio de imóveis, gerar e acompanhar avaliações, gerenciar o relacionamento com clientes no CRM, e — quando ativo — permitir que um cliente converse pelo WhatsApp sobre imóveis e agende visitas.

Não vendemos dados pessoais a terceiros. Dados de clientes cadastrados por um corretor pertencem à relação entre o corretor e seu cliente; o MaterImob os armazena como parte da prestação do serviço.

Onde os dados ficam armazenados

Os dados são armazenados em banco de dados hospedado pela Supabase, com controle de acesso por conta. Mensagens de WhatsApp são processadas via Meta Cloud API e um parceiro de infraestrutura de WhatsApp Business.
